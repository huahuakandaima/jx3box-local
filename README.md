# JX3 资历工作台（本地版）

剑网3 资历工具 · 本地版。只连接剑网3官方/魔盒公开接口，无账号体系、无云同步、无遥测。

> 本仓库**不开源**，仅发布编译好的 exe。

## 下载

到 [Releases](../../releases) 页面下载最新 `JX3WorkbenchLocal_x.x.x.zip`，解压后直接运行 `JX3WorkbenchLocal.exe`，无需安装 Python。

## 功能一览

| 模块 | 说明 |
|---|---|
| 魔盒 Token | 手动粘贴，或一键自动获取（拉起浏览器独立配置，读 HttpOnly Cookie） |
| 资历总览 | 分类树 / 完成度 / 搜索 / 难度标注 |
| 📊 资历规划 | 一键智能（分段配额+秘境整本补齐）/ 目标资历凑点数 |
| 🤖 AI 点评 | 任意 OpenAI 兼容端点（DeepSeek / GLM / …），四段点评+称号+推荐 |
| 📌 悬浮窗 | 游戏内置顶方案进度条，展开看每条成就攻略，打勾推进度 |
| 奇遇 | 奇遇完成状态 + 筛选 |
| 声望 | 等级自动判定（成就反推）；声望表一键生成 |
| 科举 | 截图取题（Windows 内置 OCR 免密钥）/ 粘题 → 本地题库（自动积累）→ 在线匹配 |
| 提醒 | 本地提醒（每日/每周）+ 彩色便签 |
| 其他 | 系统托盘、资历快照导出 Markdown |

## 快速上手

1. 首次启动：菜单 `数据 → 设置`，填写魔盒 Token（推荐「自动获取」）
2. `数据 → 刷新成就库`（首次必做，之后走 24h 快照）
3. 顶栏选角色 → 开始用
4. AI 点评需在设置里填 OpenAI 兼容的 Base URL / Key / 模型

数据目录 `~/.jx3box_local/`，删除即完全重置。

## 系统要求

- Windows 10/11 x64
- 截图取题需系统装有中文语言包（默认中文系统已带）
- 自动获取 Token 需本机装有 Edge 或 Chrome

## 说明

- 本工具仅调用剑网3官方/魔盒（jx3box.com）公开网页接口，与游戏客户端无任何交互
- 请勿用于任何违反游戏用户协议的用途；使用产生的一切后果自负
- Token 仅保存在你自己电脑上，本工具没有任何服务器
